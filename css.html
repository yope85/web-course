בשביל מה זה

HTML בונה את השלד, ו-CSS הוא המראה: צבעים, גופנים, מרווחים ויישור. בהגשה 1 כל העיצוב יהיה בקובץ CSS חיצוני אחד, ו-25 נקודות במחוון ניתנות על התרשמות כללית מהעיצוב.

💡 רוצים לראות CSS אמיתי עכשיו? לחצו F12 על הדף הזה עצמו. כל מה שאתם רואים כאן מעוצב ב-CSS – ותוכלו לשנות ערכים ולראות מה קורה.

שלוש דרכים להוסיף עיצוב

שיטהאיפה כותביםמתי

Internalבתגית style בתוך ה-headלדף בודד
Externalבקובץ נפרד עם סיומת css, שמחובר בתגית linkהשיטה שלנו: קובץ אחד לכל הדפים

כך מחברים קובץ חיצוני מדף שנמצא בתיקייה HTML (עולים תיקייה אחת למעלה ונכנסים ל-css):

<link href="../css/style.css" rel="stylesheet" />

כלל CSS בנוי מבורר (selector) – את מי מעצבים, ובתוך סוגריים מסולסלים זוגות של מאפיין: ערך;

p {
    color: navy;
    font-size: 18px;
}

🔬 מודל הקופסה גוררים ורואים

כל תגית היא קופסה עם ארבע שכבות, מבפנים החוצה: תוכן ← padding (ריפוד – רווח בתוך המסגרת) ← border (מסגרת) ← margin (שוליים – רווח מחוץ למסגרת, בין הקופסה לשכנות שלה). הזיזו כל פס בנפרד, ושימו לב מה זז.

הטקסט שלי

          

        

      

    

    
💡 הכלל: Inline גובר על כולם. אחריו – כלל ספציפי גובר על כללי: id חזק מ-class, ו-class חזק משם תגית. כשהכללים שווים – מנצח מי שנכתב אחרון. ועוד דבר: חלק מהמאפיינים, כמו צבע וגופן, עוברים בירושה לתגיות הפנימיות; מסגרת ושוליים – לא.

div לעומת span
שתיהן "קופסאות" בלי עיצוב משלהן. div תופסת שורה שלמה ועוטפת כמה תגיות; span עוטפת רק חלק מתוך שורה – למשל מילה אחת שרוצים לצבוע.

    ✅ בדקו את עצמכם
    
    
    יש לכם 10 דפי תוכן. למה עדיף קובץ CSS חיצוני אחד על פני style בכל דף?
    כי משנים במקום אחד וכל הדפים מתעדכנים יחד – וכל הדפים נראים אחידים, בדיוק מה שהמחוון בודק.
    
    
    הגדלתם padding. הכרטיס גדל או רק התרחק מהשכנים?
    גדל. padding הוא רווח בתוך המסגרת. כדי להרחיק בלי להגדיל – משנים margin.
    
    
    לתגית יש גם class וגם id, ולכל אחד כלל עם צבע אחר. איזה צבע ינצח?
    הצבע של כלל ה-id, כי id ספציפי יותר מ-class – לא משנה איזה נכתב קודם.
